# Seguridad de DEUCE

No publiques credenciales, datos del servidor ni detalles explotables en una incidencia pública.

Comunica una vulnerabilidad mediante la opción **Report a vulnerability** de la pestaña Security del repositorio. Incluye el componente afectado, el impacto, los pasos mínimos de reproducción y cualquier mitigación conocida. Se confirmará la recepción antes de divulgar una corrección.

Las dependencias se revisan automáticamente y las publicaciones de producción solo se realizan desde una revisión que haya superado las puertas de calidad, datos, navegador y recuperación.
